# 交易复盘工作台

## 本地启动

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 真实行情

当前默认使用东方财富行情接口，不需要 Token。在“行情环境”中点击“刷新东财行情”，系统会获取当前 A 股市场宽度、涨跌停池、上证/深证/创业板指数及行业与概念板块排行。

项目仍保留 Tushare 适配器作为备用数据源。如需备用，可在 `.env.local` 中填写 `TUSHARE_TOKEN`；令牌只在服务端读取，不会发送到浏览器或写入数据库。

## 市场阶段模型

模型综合上涨家数占比、涨停/跌停数量和核心指数平均涨幅，输出 0–100 的环境分、置信度、市场阶段、适合手法与建议规避手法。阶段包括冰点、修复、启动、发酵、高潮、分歧、退潮和混沌轮动。

每笔交易可标注当时的市场阶段。系统优先使用相同环境下的个人历史样本计算手法胜率和平均收益；样本不足时退回全量历史样本，并在界面明确标识。
